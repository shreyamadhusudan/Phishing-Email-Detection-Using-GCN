# Phishing-Email-Detection-Using-GCN
This project uses Graph Convolutional Networks (GCN) to detect phishing emails based on the semantic and structural features of the email content.

## Overview

Traditional phishing detection relies on URLs or blacklists, which are often bypassed by evolving phishing strategies. This project focuses on **natural language analysis** using **graph-based deep learning** to detect deceptive content in emails.

## Technologies Used

- Python
- PyTorch / DGL (Deep Graph Library)
- Natural Language Processing (NLP)
- Graph Convolutional Networks (GCN)

## Features

- Text preprocessing and tokenization
- Graph construction from email content
- GCN-based classification of phishing vs legitimate emails
- Evaluation metrics for model performance
